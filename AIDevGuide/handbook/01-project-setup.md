## 1. Project setup (there is no working `tyhp init` yet)

⚠️ `tyhp init` is a stub — scaffold by hand. A project is just a `tyhp.json` plus your sources.

**Minimal `tyhp.json`** — you *must* set `include`; there is no built-in default, so an empty/missing
`include` builds nothing:
```json
{
  "include": ["src/**/*.tyhp"],
  "exclude": ["vendor/**", "build/**"],
  "output":  { "path": "build/", "phpVersion": "8.4", "strictTypes": true, "comments": true }
}
```

**Recommended layout** (convention, not enforced): `src/` sources → `build/` compiled PHP →
`tyhpdef/` your hand-written external declarations.

**Namespace → folder mapping (important):** the emitter writes each class to
`{output.path}/<Namespace/Segments>/<Class>.php` derived **from its FQN**. So `\App\Models\User` →
`build/App/Models/User.php`. ⚠️ The `psr4` config key does **not** remap output folders — it only
feeds generated `composer.json` autoload ([§2](02-autoloading.md)). Namespace-level functions go to
`<Ns/Segments>/_functions.php`; non-class/entry-point files mirror their source path.

**Mixing file types:** `.tyhp` and `.php` can coexist in one project/namespace. A `.php` file under
`include` is **parsed and re-emitted** (not copied byte-for-byte) — it goes through bind/check/emit
like Tyhp. `.tyhpdef` files are consumed for types only and never emitted.

**Layout-relevant config keys:**

| Key | Default | Effect |
|-----|---------|--------|
| `include` / `exclude` | *(none)* | Source globs. No default — set `include`. |
| `type` | `"application"` | `"library"` flips `build.generateTyhpdef` on (⚠️ tyhpdef gen largely placeholder). |
| `output.path` | `"build/"` | Emit + `composer.json` target dir. |
| `output.namespacePrefix` | `null` | Prepended to emitted namespaces **and** output path segments. |
| `output.phpVersion` | `"8.4"` | Emit/tyhpdef targeting. Property hooks are emitted verbatim today, so keep `8.4` if you use them; ⚠️ automatic < 8.4 downlevel is planned. |
| `output.strictTypes` | `true` | Injects `declare(strict_types=1);`. |
| `output.comments` | `true` | `// Generated by Tyhp compiler` header (keep on while debugging). |
| `psr4` | `null` | **Composer autoload only** — not emitter paths. |
| `build.updateComposer` | `false` | Generate/merge output `composer.json` + run `composer install` ([§2](02-autoloading.md)). |
| `build.entryPointAutoloader` | `null` | Injects `require_once` into entry-point files ([§2](02-autoloading.md)). |
| `psr4Includes` | `null` | ⚠️ parsed, no effect. `include_tag`, `build.watch`, `build.generateSourcemap` — ⚠️ unimplemented. |
