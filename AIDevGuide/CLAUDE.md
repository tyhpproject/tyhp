# Writing Tyhp in this project

This project uses **Tyhp** (PHP 8.x plus static typing and a few additions). The full agent
instructions live in **`AGENTS.md`** in this folder — read it first.

Quick orientation:
- Start from `QUICK_GUIDE.md` (the index); follow each feature's `→` pointer to the exact file.
- Language reference: `guide/` (one file per section; see `guide/00-index.md`).
- Setup / CLI / interop / testing / runtime API: `handbook/` (see `handbook/00-index.md`).
- Open the referenced section file before writing a feature — don't guess syntax from the analogy.
- `⚠️` = not supported yet; use the noted alternative. Anything uncovered behaves like plain PHP 8.x.
